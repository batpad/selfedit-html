It's an ordinary HTML file — with a resident editor. Click the ✎ button in the corner and tell it what this page should become.

First time?

  1. Click ✎ (bottom-right) → ⚙ Settings → paste your model API key (an OpenRouter key works for everything) and pick a model.
  2. Ask for anything in the chat: "turn this into my personal homepage", "make it warm and minimal".
  3. Press Save when you like what you see — the file itself is updated.
  4. The ? button in the editor explains everything else.

Delete this box whenever you're ready (select it with ⌖ and hit delete, or just ask the agent).
